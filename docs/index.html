Los tres modelos

Qué empuja la decisión

Cada variable se lleva a su valor típico y se mide cuánto cambia el riesgo. En rojo lo que sube el riesgo y en verde lo que lo baja.

Del dato a la decisión

  1. Datos de entradaTiempo, monto y 28 componentes anonimizados de cada transacción.
  2. PreprocesamientoHora del día en forma circular, logaritmo del monto y escalado robusto, con los mismos parámetros del entrenamiento.
  3. ModelosRed neuronal de 31 → 128 → 64 → 32 → 1 neuronas y XGBoost con 36 árboles. El ensamble promedia la posición de riesgo de los dos.
  4. DecisiónSe compara el riesgo con un umbral elegido para minimizar el costo, donde un fraude perdido pesa como 50 alertas falsas.

El riesgo se muestra como un puntaje de 0 a 100 y no como una probabilidad. La red se entrenó con pérdida focal y XGBoost con un peso grande para los fraudes, así que sus salidas sirven para ordenar las transacciones por riesgo pero no para leerlas como porcentaje de certeza. Por eso el umbral se expresa como la proporción de transacciones más riesgosas que se envía a revisión.

Desempeño en datos nunca vistos

Conjunto de prueba: las transacciones más recientes del periodo, con fraudes. Ninguna se usó para entrenar ni para elegir el umbral.

Límites que conviene conocer

  • Los datos son de tarjetas europeas de 2013; el fraude actual puede tener otros patrones.
  • Las variables V1 a V28 están anonimizadas, así que el modelo no puede usar el historial del cliente ni el tipo de comercio.
  • Uno de cada cinco fraudes recibe un riesgo bajo: se parecen demasiado a transacciones normales.
  • Es una herramienta de apoyo para priorizar revisiones, no una decisión automática de bloqueo.
